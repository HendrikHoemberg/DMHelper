# Release Notes — Readiness Program

## Delivery Items 1–10

- **Item 1 (P0 interaction reliability):** Quick notes, destinations, browser guards, secure package assets, visible/retryable session mutations, correlated failures, and honest difficulty estimates are implemented.
- **Item 2 (Campaign contract v1):** Schema, DTO, dry-run, import, references, and checked fixtures share one contract.
- **Item 3 (Campaign package v2 foundation):** ZIP/JSON containers, stable keys, typed catalog, preview, migrations, staged assets, and atomic import are implemented.
- **Item 4 (Current persisted campaign state recovery):** Default export/import preserves all currently persisted campaign meaning.
- **Item 5 (Combat log/dice recovery):** Included by default and explicitly excludable.
- **Item 6 (Structured scenes and quests):** Scene transitions (CHOICE/ENTRANCE/EXIT) with typed references, mutual exclusion, and deferred resolution on import. Quests with status lifecycle, objectives with ALL/ANY completion mode, prerequisite dependency DAG, and session objective-change history.
- **Item 7 (Non-statblock custom content and character creation):** Package refs for sheets/treasury, provenance, and create/clone/promote across library types. Class/subclass/skill choices and hit-die roll or average.
- **Item 8 (At-table mechanics and inventory):** Sheet attacks/features with roll expressions; live HP/temp/death saves/conditions; inventory states (EQUIPPED/CARRIED/STASHED/CONSUMED/LOST) with attunement constraints; rest preview and apply; multi-member batch operations.
- **Item 9 (Encounters and combat management):** Encounter library multi-add and groups, waves/reserves/spawn, prep notes and structured rewards, completion summaries, undo lifecycle boundaries, published map calibrate/crop/rotate/lock, named map regions, and DM/player map layer split.
- **Item 10 (Documentation and agent SDK):** DM manual, campaign format docs, architecture references, capability manifest API, validation error catalog, and documentation contract tests are in place.
